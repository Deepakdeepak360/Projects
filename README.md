# Modern E-Commerce Platform

## 🌟 Overview

A modern, responsive e-commerce platform built with HTML, CSS, and JavaScript. This project features a sleek user interface, dynamic product management, and an integrated chatbot for enhanced customer service.

## ✨ Features

### 🎯 Core Features
- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Dynamic Product Display**: Grid-based product layout with smooth animations
- **Advanced Search**: Real-time product search functionality
- **Shopping Cart**: Interactive shopping cart with quantity controls
- **User Profiles**: Customizable user profiles with avatar support

### 🎨 UI/UX Features
- **Animated Banner**: Dynamic carousel with smooth transitions
- **Loading Skeletons**: Smooth loading states for better user experience
- **Interactive Elements**: Hover effects and smooth transitions
- **Stock Indicators**: Visual indicators for product availability

### 🛒 Shopping Features
- **Quick Buy Options**: One-click purchase functionality
- **Cart Management**: Add/remove items with quantity controls
- **Category Navigation**: Easy browsing through product categories
- **Price Filters**: Sort and filter products by price range

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- PHP 7.4 or higher
- MySQL 8.0
- Apache/Nginx web server

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Deepakdeepak360/e-commerce.git
   ```
2. Navigate to the project directory:
   ```bash
   cd e-commerce
   ```
3. Set up your web server:
   - Configure Apache/Nginx to point to the project's root directory
   - Ensure PHP is properly configured with MySQL support

4. Configure database:
   - Create a new MySQL database
   - Import the database schema from `database/schema.sql`
   - Update database connection settings in `config/database.php`

5. Configure Chatbot (Optional):
   - Update chatbot settings in `config/chatbot.php`
   - Add your chatbot API credentials

### Development
```bash
# Start PHP development server (alternative to Apache/Nginx for local development)
php -S localhost:8000
```
